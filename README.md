# Salle de jeux

Lanceur iPad (PWA) qui réunit mes jeux publiés sur `louskyfly.github.io` :
Vol libre, Base spatiale, Défense robots, City Builder et Détective.

**Jouer :** https://louskyfly.github.io/salle-de-jeux/

- Chaque jeu s'ouvre en plein écran dans une iframe de la même origine : les sauvegardes et records (localStorage) sont partagés, et les jeux sont toujours à jour.
- Bouton ☰ semi-transparent (déplaçable, position mémorisée par jeu) : continuer, revenir à l'accueil ou relancer le jeu.
- Sur iPad : Safari › Partager › **Sur l'écran d'accueil** pour l'avoir en plein écran comme une appli.

Ajouter un jeu : une entrée dans le tableau `GAMES` de `index.html` (+ une image dans `img/`).
